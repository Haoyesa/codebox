## 内容节奏说明

### 发布时间
- 早间：7:30-8:30（职场人群）
- 午间：12:00-13:00（碎片时间）
- 晚间：20:00-22:00（黄金时间）

### 内容类型比例
```
干货文：30%（专业价值）
故事型：20%（情感连接）
清单型：20%（实用价值）
教程型：15%（工具价值）
福利型：10%（引流转化）
讨论型：5%（互动活跃）
```

### 选题方向参考

**副业方向**
- 技能变现（写作/设计/编程/翻译）
- 平台副业（闲鱼/小红书/抖音/知乎）
- 知识付费（卖课/咨询/社群）
- 电商带货（无货源/代发/自营）

**职场方向**
- 效率工具（Excel/PPT/Word）
- 职场技能（沟通/汇报/时间管理）
- 晋升加薪（升职攻略/谈薪资）
- 求职转型（简历/面试/转行）

---

## 注意事项

1. **固定发布时间**：选择固定时间段培养粉丝习惯
2. **保持垂直**：专注副业+职场两个方向，不要跑偏
3. **真实人设**：用自己的真实经历更有说服力
4. **及时互动**：回复评论，提高账号活跃度
5. **数据复盘**：每周看数据，调整内容方向
