# 职场面试自我介绍万能逐字稿（5篇）

> 2-3分钟口播 · 可直接背诵使用

---

## 【版本1】应届生通用版

```
【时长】约2分钟 | 【字数】约600字

面试官您好，我是[姓名]，很高兴能参加今天的面试。

我是[学校][专业]的应届毕业生，在校期间我学习认真，成绩排名专业前15%，多次获得奖学金。

除了学习之外，我也注重实践经验。去年暑假，我在[公司名称]进行了为期三个月的实习，主要负责[工作内容]。在这段实习经历中，我[取得了什么成果/学到了什么技能]，这让我对[行业/岗位]有了更深入的理解，也锻炼了我[某方面能力]。

在校期间，我还担任[学生会/社团]的[职务]，参与组织了[活动名称]等大型活动。这些经历锻炼了我的沟通协调能力和团队协作精神。

我应聘的是[岗位名称]岗位。我认为这个岗位需要[岗位核心能力要求]，而我[为什么觉得自己匹配]，比如[举一个相关的经历或能力]。

如果能加入贵公司，我希望能在[方向]为公司创造价值，同时也希望能在实践中不断学习和成长。

以上就是我的自我介绍，谢谢！
```

## 面试注意事项

```
❌ 不要说：
· "我没有经验，但是我愿意学习"（太虚）
· "我的缺点是太追求完美"（太假）
· "工资期望..."（第一次面试不宜主动提）
· 念简历（面试官自己会看）

✅ 要说：
· 有数据支撑的成果
· 与岗位匹配的能力
· 对公司和岗位的了解
· 真诚+自信的态度

💡 加分技巧：
· 提前练习，控制在2-3分钟
· 语速适中，不要太快
· 适当的眼神交流
· 结尾主动表达期待
```
