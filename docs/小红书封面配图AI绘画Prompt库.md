## 一、基础风格定义

### 1.1 核心风格关键词

```
【主风格】
 minimalist | modern | clean | professional
（极简 / 现代 / 干净 / 专业）

【辅助风格】
editorial design | magazine style | flat design
（编辑设计 / 杂志风 / 扁平设计）

【色调】
warm beige | soft gray | muted blue | elegant gold
（暖米色 / 柔灰 / 雾蓝 / 雅金）

【质感】
matte texture | subtle gradient | soft shadow
（哑光质感 / 微妙渐变 / 柔和阴影）
```

### 1.2 通用构图公式

```
【公式1：文字为主型】
背景（纯色/渐变/几何） + 叠加文字 = 封面

【公式2：场景代入型】
俯拍桌面（书本/电脑/咖啡）+ 留白区域 = 知识干货感

【公式3：人物+信息型】
侧脸/背影/手部动作 + 文字区 = 个人IP风格

【公式4：数据展示型】
图表元素 + 数字 + 关键词 = 专业感
```

### 1.3 必备元素词

```
✅ 加分元素：
· geometric shapes（几何形状）
· soft gradient（柔和渐变）
· subtle shadow（微妙阴影）
· clean typography（简洁排版）
· abstract lines（抽象线条）
· soft light（柔和光线）
· minimalist icons（简约图标）

❌ 避免元素：
· realistic photo（过于写实）
· cartoon/anime（卡通/二次元）
· overly colorful（色彩过杂）
· cluttered（杂乱）
· vintage/retro（复古/过时）
```

## 四、进阶技巧

### 4.1 颜色关键词

```
【适合小红书的配色】
· Warm Beige & Soft Gray（暖米+柔灰）
· Navy & Gold（深蓝+金）
· Emerald & Cream（翠绿+米白）
· Dusty Blue & Blush（雾蓝+腮红）
· Charcoal & White（炭灰+白）
· Sage Green & Tan（鼠尾草绿+棕）

【避免的颜色】
· 过于鲜艳的高饱和色
· 大面积紫色/粉色（显得廉价）
· 过多颜色混搭
```

### 4.2 光线关键词

```
【推荐光线】
· Natural sunlight（自然阳光）
· Soft diffused light（柔和散射光）
· Warm ambient lighting（温暖环境光）
· Studio soft lighting（工作室柔光）

【避免光线】
· Harsh direct sunlight（刺眼直射光）
· Dramatic high contrast（强对比戏剧光）
```

### 4.3 材质关键词

```
【加分材质】
· marble texture（大理石纹理）
· leather surface（皮革表面）
· wooden desk（木桌）
· matte finish（哑光质感）
· premium paper（优质纸张）

【避免材质】
· plastic texture（塑料质感）
· worn wood（破旧木头）
· overly glossy（过于光亮）
```

### 4.4 构图技巧

```
【黄金构图比例】
· 主体占画面60-70%
· 留白区域40-50%（供文字叠加）
· 文字安全区：画面上1/3或下1/3

【常用构图方式】
1. 俯拍45度角（最常用）
2. 完全俯拍90度（极简风）
3. 侧面俯拍（左高右低）
4. 留白俯拍（主体偏左/偏右）
```

## 七、常见问题与解决

```
Q1：生成的图文字区域不够？
→ 添加 "abundant white space for text" 或 "text safe zones"

Q2：背景太花哨？
→ 添加 "clean background" 或 "minimalist surface"
→ 或用 "pure white background"

Q3：颜色不够统一？
→ 明确指定主色："warm beige and soft gray tones"
→ 或 "navy and gold color scheme only"

Q4：风格太AI感？
→ 加 "--style raw" 参数
→ 添加 "professional photography" 而非 "illustration"

Q5：画面太暗/太亮？
→ 调整光线："soft warm lighting" 或 "bright natural lighting"
```
