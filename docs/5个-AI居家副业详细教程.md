# 副业一：AI写文变现

## 这个副业做什么

用ChatGPT帮别人写文案，不需要露脸，不需要直播。

**你能写的类型：**
- 公众号文章
- 小红书笔记
- 产品详情页
- 短视频脚本
- 朋友圈文案
- 工作报告

## 为什么适合居家

完全线上操作，有电脑就能做。
不需要跟客户见面，文字沟通即可。
不需要任何设备，一台电脑全搞定。

## 详细操作步骤

### 第一步：准备工具（1天）

**注册ChatGPT**
1. 访问 chat.openai.com
2. 用邮箱注册账号
3. 完成验证，开始使用

**备用工具（国内可用）：**
- 讯飞星火（xunfei.cn）
- 文心一言（yiyan.baidu.com）
- 智谱清言（chatglm.cn）

### 第二步：确定接单方向（2-3天）

**选择标准：你熟悉哪个领域**
- 职场类（简历、汇报、演讲稿）
- 副业类（小红书运营、变现干货）
- 商业类（产品介绍、详情页）
- 教育类（家长沟通、育儿知识）
- 情感类（情感故事、励志文案）

**调研方法：**
1. 打开闲鱼，搜索"代写"
2. 看哪些类型单子多、价格高
3. 选择1-2个方向开始做

### 第三步：发布服务（1天）

**闲鱼发布：**
标题：
```
AI代写服务 | 文章撰写 | 商业文案 | 小红书笔记 | 公众号文章
```

内容：
```
【AI代写服务】

快速、专业、性价比高

服务类型：
• 公众号文章：200元/千字
• 小红书笔记：150元/篇
• 产品详情页：200元/页
• 短视频脚本：100元/分钟
• 工作报告：面议

✅ 满意后再付款
✅ 免费修改一次
✅ 加急不加价

发我需求，给你报价
```

### 第四步：接单交付（持续）

**接单流程：**
```
客户发需求 → 确认需求和价格 → 收款 → 用AI生成 → 人工优化 → 交付
```

**报价参考：**
| 类型 | 价格 |
|------|------|
| 500字短文 | 100-200元 |
| 1000字文章 | 200-400元 |
| 2000字长文 | 400-800元 |
| 商业文案 | 300-1000元 |

## 变现路径

**新手期（1-2个月）**
- 每天接2-3单
- 单价100-300元
- 月入3000-6000元

**成长期（3-6个月）**
- 建立客户口碑
- 逐步提价到200-500元/篇
- 月入8000-15000元

**稳定期（6个月后）**
- 老客户复购
- 包月服务（3000-8000元/月）
- 月入2-3万

# 副业二：AI做图变现

## 这个副业做什么

用AI工具帮别人生成图片，不需要露脸，不需要直播。

**你能做的图片：**
- 小红书头像/卡通形象
- 产品主图/电商图
- 营销海报/Banner
- 插画/绘本
- 壁纸/手机壁纸
- logo/VI设计

## 为什么适合居家

一台电脑，居家就能做。
不需要摄影基础、不需要设计基础。
用AI生成，比传统设计快10倍。

## 详细操作步骤

### 第一步：准备工具（1-3天）

**方案一：Midjourney（效果最好）**

1. 注册Discord（discord.com）
2. 加入Midjourney服务器
3. 订阅会员（30美元/月）

**方案二：稿定AI（国产简单）**

1. 访问 gaoding.com
2. 注册账号
3. 使用AI生成功能

**推荐：** 先用稿定AI练手，有基础后用Midjourney接高单价单

### 第二步：练习生成（7天）

**每天练习1小时，生成50张图**

练习方向：
- 头像（不同风格）
- 插画（不同场景）
- 海报（不同主题）

**常用提示词公式：**
```
[主体描述] + [风格] + [场景] + [参数]

示例：
a cute anime girl avatar, soft colors, white background --v 5 --ar 9:16
```

### 第三步：发布服务（1天）

**闲鱼发布：**
标题：
```
AI头像定制 | 卡通头像 | 照片转插画 | 微信头像定制
```

内容：
```
【AI头像定制】✨

用AI帮你做专属头像，不是画师！
比画师便宜10倍，出图快100倍！

服务类型：
• 基础头像：19.9元（1个风格）
• 精致头像：49.9元（3个风格可选）
• 商用插画：99-299元

流程：
发照片 → 我做图 → 你选图 → 拿高清图

✅ 不满意免费重做
✅ 24小时内交付
✅ 终身可用

要的评论区扣"头像"~
```

### 第四步：接单交付（持续）

**接单流程：**
```
客户发照片 → 用AI生成3-5张 → 客户选一张 → 微调（如需要）→ 交付高清图 → 收款
```

**时间控制：**
- 简单头像：10-20分钟
- 复杂插画：30-60分钟
- 商业海报：1-2小时

**新手期（1-2个月）**
- 每天接3-5单
- 单价19.9-49.9元
- 月入3000-8000元

**成长期（3-6个月）**
- 开始接商业单（100-500元/单）
- 卖素材包（被动收入）
- 月入1-2万元

**稳定期（6个月后）**

# 副业三：AI制作卖资料

## 这个副业做什么

用AI制作资料包（模板、清单、手册、教程），打包卖给需要的人。

**你能做的资料类型：**
- 简历模板合集
- PPT/Excel模板
- 工作汇报模板
- 副业教程合集
- 行业资料包
- 素材模板包

## 为什么适合居家

纯数字产品，一次制作，无限销售。
不需要物流、不需要发货，设置好后自动成交。
居家就能做，一台电脑全搞定。

## 详细操作步骤

### 第一步：确定选题（2-3天）

**选题调研方法：**
1. 打开淘宝，搜索你熟悉的领域
2. 看哪些资料销量高、评价好
3. 分析这些资料的特点

**高需求选题方向：**

职场人类：
- 简历模板100套
- 工作汇报模板50套
- PPT模板大全
- 会议纪要模板

副业类：
- 小红书运营教程
- AI副业合集
- 引流变现话术
- 副业方向选择指南

生活类：
- 减肥计划表
- 存钱计划表
- 装修流程表
- 婚礼筹备表

### 第二步：用AI生成内容（3-5天）

**内容生成提示词：**
```
你是一个[领域]专家。

任务：帮我写一份[主题]教程/手册

目标读者：[描述]
字数要求：3000-5000字

结构：
1. 认知篇（什么是、为什么需要）
2. 基础篇（核心知识）
3. 实操篇（具体步骤）
4. 进阶篇（如何做得更好）
5. FAQ

风格：口语化、实用、有干货

请开始写：
```

### 第三步：制作PDF（1-2天）

**排版要求：**
- 页面：A4
- 字体：微软雅黑/宋体
- 正文字号：10.5-12pt
- 行距：1.5倍

**封面设计（用Canva）：**
1. 打开 canva.com
2. 选择"海报"模板
3. 设计封面（标题+副标题+图）
4. 导出图片

**导出PDF：**
Word → 文件 → 另存为 → 选择PDF格式

### 第四步：上架销售（1天）

**淘宝上架：**
标题格式：
```
[资料类型] + [数量] + [适用人群] + [平台/场景]

示例：
简历模板合集 100套 求职必备 面试官都说好
小红书运营教程 2026版 副业变现实战 适合新手
```

详情页：
```
1. 产品卖点（为什么买）
2. 内容介绍（有什么）
3. 适用人群（谁需要）
4. 使用方法（怎么用）
5. 常见问题（FAQ）
6. 购买须知（售后说明）
```

### 第五步：设置自动发货（1天）

**用千牛自动发货：**
1. 购买自动发货插件
2. 上传资料到阿里云盘
3. 设置自动发货（网盘链接+提取码）
4. 客户付款后自动发送

**定价参考：**
| 类型 | 价格 |
|------|------|
| 单个模板包 | 9.9-29.9元 |
| 模板合集（50+） | 29.9-99元 |
| 系统教程 | 49.9-199元 |
| 大全/合集 | 99-299元 |

## 变现路径

**新手期（1-2个月）**
- 制作3-5个资料产品
- 上架多个平台
- 月入2000-5000元

**成长期（3-6个月）**
- 制作10-20个产品
- 建立素材包矩阵
- 月入8000-15000元

**稳定期（6个月后）**
- 产品数量30+
- 多平台分发
- 被动收入为主
- 月入2-5万

# 副业四：AI提示词模板销售

## 这个副业做什么

整理和卖AI工具的提示词模板，帮助别人更好地使用AI。

**你能做的提示词类型：**
- ChatGPT提示词模板
- Midjourney提示词模板
- AI写作提示词合集
- 各行业AI应用模板

## 为什么适合居家

纯数字产品，整理和售卖都是线上完成。
不需要任何设备，一台电脑就够。
边际成本为零，一份模板可以卖无数次。

## 详细操作步骤

### 第一步：学习提示词基础（3-5天）

**理解提示词是什么：**
- 提示词 = 告诉AI你要什么
- 好提示词 = 让AI给出你想要的结果

**常用提示词公式：**

```
# 角色法
你是一个[角色]。请帮我[任务]。

# 例子法
请按照以下例子写：[例子]

# 结构法
请按照以下结构输出：
1. ...
2. ...
3. ...
```

### 第二步：整理提示词模板（5-7天）

**按领域整理：**

职场类：
- 简历优化提示词
- 工作汇报提示词
- 会议纪要提示词
- 演讲稿提示词

副业类：
- 小红书文案提示词
- 产品介绍提示词
- 引流话术提示词
- 朋友圈文案提示词

创意类：
- 故事创作提示词
- 短视频脚本提示词
- 品牌命名提示词
- logo设计提示词

**整理格式：**
```
【模板名称】
用途：[描述]
提示词：[完整提示词内容]
适用场景：[说明]
使用示例：[举例]
```

### 第三步：制作成产品（2-3天）

**产品形式：**
- 单个模板包：29.9-99元
- 合集模板包：99-299元
- 教程+模板：199-499元

**制作产品包：**
1. 用Word整理所有模板
2. 用Canva设计封面
3. 导出PDF格式
4. 打包发送

### 第四步：多平台销售（1天）

**上架平台：**
- 淘宝（搜索"AI提示词"）
- 闲鱼（搜索"提示词模板"）
- 小红书（发使用教程引流）
- 知识星球/小报童（付费专栏）

**标题格式：**
```
[数量]个ChatGPT提示词 | [领域] | [用途]

示例：
100个ChatGPT提示词 | 职场人必备 | 写简历/汇报/邮件
50个Midjourney提示词 | 头像设计 | 小红书爆款头像
```

### 第五步：持续更新（持续）

- 每周新增提示词
- 收集用户反馈
- 迭代优化版本

## 变现路径

**新手期（1-2个月）**
- 整理50-100个提示词
- 上架多个平台
- 月入2000-5000元

**成长期（3-6个月）**
- 持续更新迭代
- 建立品牌认知
- 月入8000-15000元

**稳定期（6个月后）**
- 推出付费课程
- 建立社群
- 月入2-5万

# 副业五：AI小红书账号运营

## 这个副业做什么

用AI工具做小红书账号，通过接广告、带货、卖资料变现。

**账号定位方向：**
- 职场干货（简历/汇报/技能）
- 副业赚钱（AI副业/兼职方向）
- 资料分享（模板/清单/教程）
- 好物推荐（家居/办公/数码）

## 为什么适合居家

完全线上操作，居家就能做。
不需要露脸，图文内容为主。
AI工具大幅提升内容生产效率。

## 详细操作步骤

### 第一步：确定账号定位（2-3天）

**选择方向（根据你熟悉的领域）：**

| 方向 | 内容类型 | 变现方式 |
|------|----------|----------|
| 职场干货 | 简历/汇报/技能教程 | 接广告、卖资料 |
| 副业赚钱 | AI副业/兼职方向 | 卖课、卖社群 |
| 资料分享 | 模板/清单/教程 | 卖资料、接广告 |
| 好物推荐 | 家居/办公好物 | 带货佣金 |

**调研方法：**
1. 搜索你选择的关键词
2. 看哪些账号做得好、怎么做的
3. 确定你的差异化方向

### 第二步：注册账号+完善主页（1天）

**主页设置：**
头像：清晰、有记忆点
昵称：好记 + 领域关键词
简介：身份 + 能提供什么价值

**简介模板：**
```
[身份] | [专业领域]
分享：[内容方向]
帮助：[目标人群]
➕关注，持续输出[领域]干货
```

### 第三步：用AI生产内容（持续）

**AI写小红书文案：**
```
你是一个小红书博主。

任务：帮我写一篇[主题]小红书笔记

要求：
- 字数：600-800字
- 风格：口语化、有共鸣、有干货
- 目标读者：[描述]
- 结构：开头痛点 + 正文3点 + 结尾引导

标题：[给3个备选标题]

请开始写：
```

**AI生成配图：**
1. 用稿定AI或Canva做图
2. 或用Midjourney生成素材图
3. 保持风格统一

**发布节奏：**
- 每天1篇
- 或每天2篇（早晚各一）
- 固定时间发布（7-8点、12-13点、20-22点）

### 第四步：引流变现（持续）

**变现方式一：接广告**
- 1000粉丝可以接广告
- 单条广告：200-2000元
- 品牌合作路径：通告平台接单

**变现方式二：带货**
- 开通带货权限
- 写种草笔记
- 赚取佣金（10%-30%）

**变现方式三：卖资料**
- 笔记末尾引导"想要XX丝我"
- 私信发送购买链接
- 自动发货

### 第五步：数据优化（每周）

**关键指标：**
- 浏览量（决定曝光）
- 点赞数（内容质量）
- 收藏数（价值认可）
- 评论数（互动活跃）
- 关注转化（账号价值）

**优化方法：**
- 浏览量低 → 换标题/封面
- 收藏数低 → 加强干货价值
- 评论数低 → 增加互动引导

## 变现路径

**新手期（1-3个月）**
- 发布内容，积累粉丝
- 月入0-2000元

**成长期（3-6个月）**
- 开始接广告（200-1000元/条）
- 带货佣金（500-3000元/月）
- 月入5000-15000元

**稳定期（6个月后）**
- 多账号矩阵
- 高价广告（2000-5000元/条）
- 带货+卖课
- 月入3-10万
