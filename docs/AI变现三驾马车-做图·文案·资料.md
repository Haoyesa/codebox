## 四、AI做图详细操作流程

### 第一步：确定你的图片方向

**推荐的新手起步方向（按容易程度排序）：**

| 方向 | 难度 | 需求 | 单价 | 适合人群 |
|------|------|------|------|----------|
| 头像/卡通 | ★☆☆☆☆ | 大 | 9.9-49.9元 | 有审美感 |
| 壁纸/插画 | ★★☆☆☆ | 中 | 19.9-99元 | 爱画画 |
| 产品图 | ★★★☆☆ | 大 | 50-300元 | 有电商资源 |
| 海报/Banner | ★★★☆☆ | 大 | 50-200元 | 会营销 |

### 第二步：学习提示词（核心技能）

AI做图的核心是"提示词"——你描述得越清楚，图片越符合预期。

**基础提示词公式：**
```
[主体] + [风格] + [场景] + [光线] + [色调] + [参数]

示例：
一个可爱的女孩头像，动漫风格，白色背景，柔和光线，粉色系，8k高清
```

**常用风格关键词：**
```
动漫风格：anime, cartoon, illustration
写实风格：photorealistic, realistic, 8k
插画风格：vector, flat illustration, minimalist
复古风格：vintage, retro, old style
赛博朋克：cyberpunk, neon, futuristic
水彩风格：watercolor, pastel
```

**常用质量参数：**
```
--v 5：使用版本5（Midjourney）
--q 2：高质量
--s 250：风格化程度
--ar 9:16：竖版比例（适合头像）
```

### 第三步：生成第一张图片

**以Midjourney为例：**

1. 在新手频道输入框输入 `/imagine`
2. 输入提示词，例如：
   ```
   a cute anime girl avatar, long hair, big eyes, white background, soft colors, clean, modern --v 5 --ar 9:16
   ```
3. 等待10-30秒，系统生成4张图
4. 选择满意的，U放大；不满意的，R重新生成

### 第四步：优化和调整

**调整提示词的方法：**
- 颜色不对 → 加颜色词 "blue dress"
- 风格不对 → 加风格词 "oil painting style"
- 细节不够 → 加细节词 "detailed face, high resolution"
- 构图不对 → 加构图词 "upper body, centered"

**常用调整词：**
```
面部调整：
pretty face, beautiful, delicate features, detailed eyes

背景调整：
simple background, white background, bokeh, gradient background

整体风格：
clean, minimalist, detailed, high quality, 8k

表情调整：
smile, cute expression, happy, confident
```

## 四、AI写文案详细操作流程

### 第一步：明确客户需求

**接单前要问清楚：**
```
1. 用途是什么？（公众号/小红书/产品页）
2. 目标读者是谁？（职场人/宝妈/学生）
3. 字数要求多少？（500字/1000字/2000字）
4. 风格偏好？（正式/活泼/专业/口语）
5. 有没有参考资料？（客户提供内容/案例）
```

**需求确认模板：**
```
您好！感谢咨询AI代写服务~

为了给您提供最合适的内容，请告诉我：

📝 内容类型：
📏 字数要求：
🎯 目标读者：
✨ 风格偏好：
📚 参考资料：（如果有的话）

确认后我会给您报价，满意后再下单~
```

### 第二步：写提示词

**好提示词 = 角色 + 任务 + 要求 + 格式**

**提示词模板：**
```
你是一个[领域]资深内容专家。

任务：帮我写一篇[类型]，用于[用途]

要求：
- 目标读者：[描述]
- 字数：[X]字
- 风格：[描述]
- 核心信息：[要传达的重点]

格式：
1. 开头：[要求]
2. 正文：[要求]
3. 结尾：[要求]

请开始写：
```

**示例提示词：**
```
你是一个小红书运营专家。

任务：帮我写一篇小红书笔记，主题是"副业做什么好"

要求：
- 目标读者：想找副业的上班族
- 字数：800字
- 风格：口语化、有共鸣、有干货
- 核心信息：3个适合上班族的副业方向

格式：
1. 开头痛点（引发共鸣）
2. 3个副业方向（每个有具体说明）
3. 结尾引导关注

请开始写：
```

### 第三步：生成和优化

**AI初稿生成后，人工优化：**

- [ ] 去掉AI痕迹（太官方的表达）

### 第三步：制作成可交付的产品

**PDF制作步骤：**

**Step 1：用Word排版**
- 设置页面大小：A4
- 设置页边距：上下2.54cm，左右3.18cm
- 设置正文字号：10.5pt
- 设置行距：1.5倍

**Step 2：设置标题层级**
- 一级标题：18pt，加粗
- 二级标题：14pt，加粗
- 三级标题：12pt，加粗

**Step 3：添加页眉页脚**
- 页眉：产品名称
- 页脚：页码

**Step 4：用Canva设计封面**
- 尺寸：800×800px（闲鱼）/ 1080×1440px（小红书）
- 包含：标题 + 副标题 + 视觉元素
- 风格：醒目、专业、有吸引力

**Step 5：导出PDF**
- Word → 文件 → 另存为 → 选择PDF格式
- 检查是否清晰
