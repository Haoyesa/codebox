# 小红书私信自动回复话术10条

> 温柔不违规 · 引导领取 · 引导下单 · 规避敏感词

---

## 基础原则

```
❌ 禁用词：
· "微信"/"加我"/"vx" → 用"主页有方式"替代
· "购买"/"下单"/"付款" → 用"看看"或"了解"替代
· "便宜"/"最低" → 用"合适"/"划算"替代
· "赚钱"/"日赚" → 用"收获"/"增收"替代

✅ 替换方案：
· "私信" → "丝我"
· "购买链接" → "看看我"
· "扫码" → "点主页"
· "微信" → "方式在主页"
· "下单" → "要一份"
```

## 场景一：引导领取资料

### 话术1：引流款领取

```
亲，感谢关注～ 🌟

您想要的[模板/资料]可以在[小红书店铺/某宝]找到哦～
名字是「XXX」，点我主页置顶笔记有介绍～

有其他问题也可以问我，很乐意帮忙～ 😊
```

**适用**：客户问怎么领资料，还没到下单阶段

---

### 话术2：引导看主页

```
嗨～很高兴您能来！✨

喜欢的话可以直接带走哦～

有什么不清楚的随时问我～ 🙏
```

**适用**：刚关注，需要先建立信任再推产品

---

### 话术3：温和引导（附赠品）

```

**适用**：已有产品介绍，需要增加吸引力

```

## 注意事项

```
✅ 要点：
· 语气温柔，像朋友聊天
· 先解决需求，再引导购买
· 不要一次性发太多信息
· 适当用表情增加亲切感
· 回复要像真人，不要太机械

❌ 避免：
· 不要连续发同样内容
· 不要用太多感叹号
· 不要重复发催促下单
· 不要说"快买"/"马上"等催促词
· 不要发外部平台的名字
```
