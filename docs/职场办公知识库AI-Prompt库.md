## 使用说明

```
📌 使用方法：
1. 选择需要的分类和主题
2. 复制对应Prompt
3. 粘贴到AI工具（ChatGPT/Kimi/豆包）
4. 根据实际情况修改[ ]内参数
5. 生成内容直接使用或微调

📁 建议输出格式：
· Word文档（可编辑）
· 导出PDF（可销售）
· Markdown（知识星球/小报童）

💡 提示：
· 生成后可增加个人信息
· 适当调整格式/措辞
· 批量生成建议分批进行
```
