# 职场模板AI批量制作Prompt库

> 简历模板 · 总结报告 · PPT模板 · 批量生成 · 拿来即用

---

## 使用说明

```
📌 核心原则：
1. 每次生成多个版本（3-5个），提高效率
2. 统一风格标准，方便打包销售
3. 生成后可直接使用，也可微调
4. 批量生产时按目录结构组织

📁 输出文件命名建议：
- 简历：[编号]-[风格]-[适用人群].docx/.pptx
- 总结：[年份]-[类型]-模板.docx/.pptx
- PPT：[场景]-封面.pptx / [场景]-内容页.pptx

📦 打包结构：
├── 简历模板合集/
│   ├── 01-简约商务风-应届生.docx
│   ├── 02-专业沉稳风-3年经验.docx
│   ├── ...
│   └── 使用说明.docx
│
├── 年度总结模板/
│   ├── 01-数据增长型.pptx
│   ├── 02-项目展示型.pptx
│   └── ...
│
└── PPT模板合集/
    ├── 商务汇报/
    ├── 教学培训/
    └── 求职面试/
```

```
Q1：生成的内容格式不对？
→ 明确指定格式："请生成Word文档格式"

→ 使用"模板家族"Prompt，统一设计规范

→ 指定行业和职位："生成互联网产品经理简历模板"

→ 分批生成，每批5-10个
→ 先做模板框架，再填充内容

→ 使用"优化迭代"Prompt，针对性修改
```
