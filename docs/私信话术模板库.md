# 五、常用短句库

- 评论区扣「XX」，我私发
- 私信我「XX」，直接给你
- 有问题随时问，有问必答
- 看主页置顶，有惊喜

## 结束语
- 加油 💪
- 祝顺利 🙏
- 我们群里见
- 有问题找我

## 互动语
- 说的就是你
- 躺枪了吗
- 你中了几条
- 评论区说说

## 价值强调
- 亲测有效
- 认真学会有收获
- 照着做就行
- 这套最稳

---

## 注意事项

1. **及时性**：5分钟内回复，夜间不超过12小时
2. **温度感**：像朋友一样说话，不要太官方
3. **价值感**：每条消息都提供一点价值
4. **行动明确**：每条消息都有一个明确的行动引导
