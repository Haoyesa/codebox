# 副业起号方案AI生成器

> 一套通用Prompt · 生成完整起号方案 · 拿来即用

---

## 使用说明

```
📌 使用方法：
1. 复制下面的【完整Prompt】
2. 粘贴到ChatGPT/Kimi/豆包等AI工具
3. 按提示填写[ ]内的变量信息
4. 生成完整起号方案

💡 适用场景：
· 新账号起步迷茫 → 生成方案照做
· 转型不知道方向 → 重新生成
· 复盘优化方案 → 调整变量重生成

📁 输出文件：
· 账号定位报告
· 人设规划文档
· 内容规划表（月度）
· 引流执行方案
· 变现路径图
· 30天执行计划
```

---

## 【完整Prompt】复制使用

```
请帮我生成一份完整的副业起号方案。

## 一、我的基础信息

【个人背景】
- 职业/身份：[如上班族/宝妈/学生/自由职业]
- 擅长领域：[如职场/育儿/设计/写作/营销]
- 兴趣爱好：[如读书/美食/旅游/数码]
- 可投入时间： [如每天2-3小时/碎片时间]

【现有资源】
- 已有粉丝/流量：[如有小红书100粉/抖音500粉等]
- 可调用的资源：[如有一技之长/有货源/有素材库]
- 启动资金预算：[如1000元/500元/无预算]

## 二、我的目标

【账号目标】
- 目标平台：[小红书/抖音/闲鱼/知乎/其他]
- 目标粉丝：[如1000/5000/1万]
- 目标时间：[如3个月/半年/1年]

【变现目标】
- 期望变现方式：[卖货/接广告/引流私域/卖课/卖服务]
- 期望月收入：[如3000/5000/1万]
- 可接受的启动周期：[如1个月/3个月]

## 三、账号基础信息

【目标平台】：[如小红书]
【账号昵称】：[已有昵称/待取/让AI推荐]
【账号简介】：[已有简介/待写/让AI推荐]

## 四、需求说明

请帮我生成一份完整的起号方案，包含以下内容：

### 1. 账号定位报告
- 定位方向（细分领域）
- 目标人群画像
- 差异化优势分析
- 账号人设打造方向
- 竞争对手分析

### 2. 人设规划文档
- 头像/昵称/简介建议
- 性格标签设定
- 语言风格定位
- 专业背书构建
- 持续曝光策略

### 3. 内容规划表（30天）
- 第一个月每天发布内容规划
- 内容类型配比（如60%干货+30%种草+10%个人IP）
- 各类型内容模板框架
- 发布时间建议
- 爆款选题库（20-30个）

### 4. 引流执行方案
- 站内引流方法（评论区/私信/主页）
- 站外引流渠道（如果有）
- 引流钩子设计
- 私域沉淀路径
- 引流话术模板

### 5. 变现路径设计
- 变现产品设计（引流品+利润品+高端品）
- 定价策略建议
- 成交路径设计
- 复购机制规划
- 变现时间表

### 6. 30天执行计划
- 第1周：账号搭建期（做什么）
- 第2周：内容测试期（测什么）
- 第3周：数据优化期（优化什么）
- 第4周：变现启动期（开始赚）

## 五、格式要求

【输出格式】
- Markdown格式，方便阅读
- 每个板块用标题分隔
- 重点内容用加粗标注
- 表格/清单便于执行

【特别要求】
- 方案要具体可执行，不要空泛
- 每个步骤都要有具体操作方法
- 要考虑到我作为[职业]的时间限制
- 方案要适合[平台]的平台规则

请生成完整的起号方案。
```

## 【分模块Prompt】更精细版本

### Prompt A：账号定位生成

```
请帮我分析并生成账号定位报告。

【我的情况】
- 身份：[上班族/宝妈/学生/其他]
- 擅长：[领域]
- 想做的平台：[小红书/抖音/其他]
- 想变现的方式：[卖货/广告/引流/其他]

【需要分析】
1. 细分领域选择（3个备选）
   - 领域名称
   - 市场竞争分析（红海/蓝海）
   - 目标人群规模
   - 变现难易度

2. 差异化定位
   - 我和同行相比的独特卖点
   - 我的优势如何放大
   - 如何建立壁垒

3. 目标人群画像
   - 人群特征（年龄/职业/痛点）
   - 需求分析
   - 内容偏好

4. 账号名称/简介建议
   - 昵称3个备选
   - 简介文案3个版本

请给出分析报告和具体建议。
```

### Prompt B：人设打造生成

```
请帮我设计账号人设。

【基本信息】
- 账号类型：[知识博主/好物分享/生活记录/其他]
- 目标平台：[小红书/抖音/其他]
- 目标变现：[卖货/广告/引流/其他]

【需要设计】
1. 人设基础要素
   - 身份标签：[如"前大厂HR"/"90后宝妈"/"985毕业"]
   - 性格特点：[如"温柔专业"/"幽默风趣"/"严厉但为你们好"]
   - 语言风格：[如"接地气"/"专业权威"/"亲切温暖"]
   - 专业背书：[如"帮助500+人找到工作"/"月入过万"

2. 视觉呈现
   - 头像风格建议
   - 主页背景图建议
   - 整体视觉风格（色调/排版）

3. 内容调性
   - 标题风格
   - 正文语气
   - 互动方式

4. 人设持续性
   - 如何保持人设一致性
   - 人设崩盘风险点
   - 人设迭代方向

请设计完整人设方案。
```

### Prompt C：30天内容规划生成

```
请帮我生成30天内容规划。

【账号信息】

1. 内容类型配比
   - 干货教程型：X%

   - 个人IP型：X%

2. 每日内容规划（30天）

   - Day 2: [内容方向+类型]

3. 各类型内容模板

5. 发布时间建议
   - 最佳发布时段

```

6. 关键里程碑

请生成详细的执行计划。

## 使用场景速查

| 场景 | 推荐版本 | 说明 |
|------|---------|------|
| 纯新手第一次做 | 【完整Prompt】 | 一次性生成全部内容 |
| 想专注某个模块 | Prompt A-F | 分模块深度生成 |
| 紧急需要一个方案 | 【超级简化版】 | 5分钟出结果 |
| 有经验想做精细化 | 【进阶版】 | 包含高级策略 |

---

> **提示**：生成方案后，建议先执行2周看数据，再根据实际情况调整。不要指望一次方案就完美，执行中优化才是关键。
