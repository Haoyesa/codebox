# 付费知识库PDF制作AI Prompt库

> 一键生成目录 · 正文 · 排版 · 完整可销售

---

## 使用说明

```
📌 本Prompt库用于生成付费知识库PDF产品

📁 输出文件结构建议：
知识库资料包/
├── 01-主教程.pdf          # 核心内容
├── 02-配套清单.pdf        # 清单/表格
├── 03-使用指南.pdf        # 使用说明
├── 配套素材/
│   ├── 封面源文件/
│   ├── 可编辑Word版/
│   └── 配套图片/
└── 使用说明.txt

📝 PDF制作工具推荐：
- Word/Markdown → WPS/Word导出PDF
- 飞书文档 → 直接导出
- Notion → 导出功能
- Canva → 设计+导出
```

## 常见问题与解决

```
Q1：生成内容太长？
→ 分批次生成，每批2-3章

Q2：格式不统一？
→ 先用Prompt 13生成排版规范，所有内容按规范生成

Q3：内容重复？
→ 调整每个章节的侧重点，或生成后做去重处理

Q4：缺少案例？
→ 用Prompt 19专门生成案例故事，再补充到正文

Q5：生成速度慢？
→ 先用Prompt 3生成目录，再分段批量生成
```
