# 小红书引流私域变现 - 快速执行清单

## 核心公式
```
定定位 → 做内容 → 引私域 → 做变现
```

---

## Step 1：定定位（Week 1）

**自测三问：**
- 我有什么经验别人需要但没整理？
- 我的目标用户是谁？他们的痛点是什么？
- 我能持续输出30篇相关内容吗？

**定位公式：**
```
[人群] + [场景] + [解决方案]
例：程序员下班后做副业方向选择指南
```

**输出：**
- [ ] 1句话定位描述
- [ ] 目标用户画像
- [ ] 3个核心选题方向

---

## Step 2：做内容（Week 2-3）

**标题公式（选一种）：**
```
公式1：人群+痛点+解决方案
公式2：数字+痛点+利益
公式3：[结果] + [我做了什么]
```

**封面公式：**
```
数字 + 情绪词 + 视觉冲击
例：「3个月日咨询50+，我这样跑通小红书引流」
```

**正文结构：**
```
痛点共鸣（200字）→ 身份背书（100字）→ 方案预告（50字）
→ 干货展开（800字）→ 总结强化（100字）→ 行动引导（50字）
```

**发布节奏：**
- 每天1篇，不要超过3篇
- 稳定输出 > 数量

**输出：**
- [ ] 标题模板库（10个）
- [ ] 封面设计模板（3套）
- [ ] 3篇测试笔记

---

## Step 3：引私域（Week 3-4）

**引流钩子设计：**
```
低门槛 + 高价值 + 相关性强
例：《小红书运营资料包》免费送
```

**话术模板：**
```markdown
评论区扣「关键词」，我私发给你

或：

点我主页私信「关键词」，直接获取
```

**私信承接：**
```markdown
收到！

资料发你：[链接]

想加入[方向]分享群？
回复「进群」，我拉你

有问题随时问 🙋
```

**关键指标：**
- 私信率目标：1%+（100阅读 = 1条私信）
- 加微率目标：80%+（10条私信 = 8人加微）

**输出：**
- [ ] 引流钩子资料包
- [ ] 私信自动回复话术
- [ ] 沉淀第一批私域用户

---

## Step 4：做变现（Week 4+）

**变现路径选择：**

| 路径 | 适合人群 | 单粉价值 |
|------|----------|----------|
| 资料包 | 有整理能力 | 1-5元 |
| 咨询 | 有专业技能 | 10-50元 |
| 训练营 | 有交付能力 | 100-500元 |
| 分销 | 有选品能力 | 5-20元 |

**产品优先级：**
1. 先做低价产品（资料包/工具包）跑通流程
2. 再做中价产品（咨询/训练营）放大收入
3. 最后做高价产品（年度陪伴/合伙人）沉淀

**关键指标：**
- 单粉价值目标：10-30元/月

---

## 每日检查清单

**发布前：**
- [ ] 标题是否包含人群/痛点/解决方案
- [ ] 封面是否有点击欲望
- [ ] 文末是否有引流行动

**发布后：**
- [ ] 记录数据（曝光/阅读/私信）
- [ ] 回复每一条评论和私信
- [ ] 分析哪类内容数据好

**私域运营：**
- [ ] 早/晚各一次朋友圈
- [ ] 定期私聊高价值用户
- [ ] 每周设计一次发售

---

## 常见问题速查

**没流量？**
检查：选题是否热门 / 标题是否吸引 / 封面是否清晰

**没人加微信？**
检查：钩子是否够吸引 / 引导话术是否明确 / 私信回复是否及时

**转化低？**
检查：私域运营是否到位 / 产品是否匹配需求 / 触达频率是否足够
