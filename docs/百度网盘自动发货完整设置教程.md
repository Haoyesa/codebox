# 百度网盘自动发货完整设置教程

> 图文步骤式讲解 · 小白一看就会 · 适合做 PDF 售卖

## 前言

### 什么是自动发货？

自动发货 = 客户付款后，系统自动把百度网盘链接和提取码发送给客户，全程不需要你操作，躺着收钱。

```
客户付款 → 平台通知 → 自动发送链接 → 客户收到 → 完成交易
```

### 为什么选百度网盘？

| 对比项 | 百度网盘 | 阿里云盘 | 其他方式 |
|--------|----------|----------|----------|
| 知名度 | ⭐⭐⭐⭐⭐ 普通用户都认识 | ⭐⭐⭐ 很多人不知道 | — |
| 分享功能 | 成熟，有密码和时效设置 | 也有，但生态不如百度 | — |
| 工具支持 | 自动发货插件支持最完善 | 支持较少 | — |
| 存储空间 | 2TB 免费空间 | 1TB 免费空间 | — |
| 稳定性 | 大平台，稳定 | 大平台，稳定 | — |

**结论**：百度网盘是小白首选，工具多、用户熟悉、稳定可靠。

## 准备工作

### 需要准备的东西

| 工具 | 用途 | 是否必需 |
|------|------|----------|
| 百度网盘账号 | 存放资料 | ✅ 必需 |
| 要卖的内容 | PDF/模板/课程等 | ✅ 必需 |
| 淘宝店铺（或闲鱼/小红书） | 卖货平台 | ✅ 必需 |
| 自动发货插件 | 自动发送链接 | ✅ 必需 |
| 千牛（淘宝卖家App） | 管理订单 | 推荐安装 |

### 准备工作流程图

```
1. 准备好要卖的内容（PDF/模板/课程资料）
       ↓
2. 注册百度网盘账号（如果有则跳过）
       ↓
3. 开通百度网盘超级会员（可选，非必须）
       ↓
4. 注册淘宝店铺（如果有则跳过）
       ↓
5. 安装自动发货插件
       ↓
6. 完成设置，开始卖货
```

## 第一步：上传资料到百度网盘

### 1.1 登录百度网盘

1. 打开浏览器，输入 **pan.baidu.com**
2. 点击右上角「登录」
3. 选择登录方式（手机号码/扫码）
4. 登录成功后进入个人网盘

> **图示**：百度网盘首页 → 右上角登录按钮
> （描述：页面上方有蓝色"登录"按钮，右侧是用户头像）

### 1.2 创建文件夹存放资料

1. 进入网盘后，点击左上角「新建文件夹」
2. 命名文件夹，建议用产品名（如：简历模板合集）
3. 双击打开文件夹

> **图示**：新建文件夹按钮位置
> （描述：左侧边栏有"新建文件夹"按钮，图标是一个文件夹+加号）

### 1.3 上传你的资料

1. 点击右上角「上传」按钮
2. 选择「上传文件」或「上传文件夹」
3. 找到你要卖的内容（PDF、视频、模板等）
4. 等待上传完成

> **图示**：上传按钮位置
> （描述：页面上方有"上传"按钮，点击后出现下拉菜单，可选择文件或文件夹）

### 1.4 确认文件上传成功

上传完成后，在文件夹内可以看到已上传的文件，文件名前会有绿色对勾标记。

> **图示**：上传完成后的文件列表
> （描述：文件名前有绿色对勾，表示上传成功）

## 第二步：生成带密码的分享链接

### 2.1 选中要分享的文件

1. 进入存放资料的文件夹
2. 勾选要分享的文件（可以一次选多个）
3. 点击上方「分享」按钮

> **图示**：文件勾选和分享按钮
> （描述：文件左侧有复选框，勾选后上方出现蓝色"分享"按钮）

### 2.2 设置分享参数

弹出分享设置窗口，按以下步骤设置：

**第一步：选择分享形式**

- 选择「有密码的分享」
- 有效期建议选择「永久有效」（方便长期销售）

**第二步：创建或使用已有密码**

- 选择「设置密码」
- 系统会自动生成一个6位密码（如：abc123）
- 可以自己修改密码（建议简单好记）

> **注意**：密码不要设置得太复杂，否则客户容易输错

**第三步：获取分享链接**

- 点击「创建链接」
- 页面会显示两个内容：
  1. **链接地址**：https://pan.baidu.com/s/xxxxxxxxxx
  2. **提取码**：xxxx（6位字母/数字）

> **图示**：分享设置窗口
> （描述：弹窗中显示"有密码的分享"，下方有链接地址和提取码输入框）

### 2.3 保存链接和密码

**重要**：把链接和密码记录下来，后面设置自动发货时要用。

建议记录格式：
```
链接：https://pan.baidu.com/s/1xxxxxxxxxxxx
提取码：xxxx
```

> **提示**：建议使用密码保护功能，即使有人拿到链接不知道密码也打不开。

## 第三步：注册淘宝店铺（已有店铺可跳过）

### 3.1 进入淘宝卖家中心

1. 打开 **taobao.com**
2. 点击右上角「千牛卖家中心」
3. 登录淘宝账号

> **图示**：淘宝首页卖家入口
> （描述：首页右上角有"千牛卖家中心"入口）

### 3.2 开设店铺

1. 点击「免费开店」

**方式二：企业店铺**

需要营业执照，适合打算做大的人。

### 3.3 设置店铺基础信息

1. 设置店铺名称（建议与卖的产品相关）
2. 设置店铺图标/头像
3. 完善店铺简介

## 第四步：安装自动发货插件

### 4.1 什么是自动发货插件？

自动发货插件 = 代替你手动发送百度网盘链接的工具。客户付款后，插件自动把链接和密码发送给客户。

### 4.2 主流自动发货插件对比

| 插件名称 | 支持平台 | 费用 | 特点 |
|----------|----------|------|------|
| 订单天使 | 淘宝 | 免费基础版/付费专业版 | 功能全面，新手友好 |
| 智能自动发货 | 淘宝 | 免费/付费 | 操作简单 |
| 闲鱼自动发货助手 | 闲鱼 | 免费/付费 | 闲鱼专用 |

**推荐新手用「订单天使」**，功能全、操作简单、教程多。

### 4.3 安装订单天使

#### 电脑端安装

1. 打开订单天使官网：**www.dingdanangel.com**
2. 点击「下载安装」
3. 下载电脑版客户端
4. 双击安装包，按提示完成安装
5. 打开软件，登录淘宝账号

> **图示**：订单天使官网下载页面
> （描述：首页有明显的"免费下载"按钮）

#### 手机端安装

1. 打开千牛APP
2. 搜索「订单天使」
3. 点击「添加应用」
4. 完成授权

### 4.4 订单天使基础设置

**第一步：绑定淘宝店铺**

1. 打开订单天使
2. 点击「店铺管理」
3. 点击「添加店铺」
4. 选择淘宝店铺类型
5. 授权登录

> **图示**：订单天使店铺绑定页面
> （描述：左侧菜单有"店铺管理"，点击后右侧显示添加店铺按钮）

**第二步：设置发货内容**

1. 点击左侧「发货内容」
2. 点击「新增发货内容」
3. 填写以下信息：
   - **名称**：填写产品名称（如：简历模板合集）
   - **类型**：选择「百度网盘」
   - **链接**：粘贴百度网盘分享链接
   - **提取码**：填写6位提取码

> **图示**：发货内容设置页面
> （描述：表单中有"名称"、"链接"、"提取码"等输入框）

**第三步：创建发货规则**

1. 点击左侧「发货规则」
2. 点击「新建规则」
3. 设置规则名称（如：自动发货-简历模板）
4. 关联对应的发货内容
5. 设置触发条件（付款后自动发货）
6. 保存规则

> **图示**：发货规则创建页面
> （描述：规则设置页有"触发条件"和"发货内容"两个关键配置项）

## 第六步：测试自动发货流程

### 6.1 测试重要性

** 반드시 测试！不测试就上线等于盲人开车。**

### 6.2 测试步骤

**第一步：用小号拍下自己的商品**

1. 准备一个另外的淘宝账号（或者让朋友帮忙）
2. 搜索你的商品
3. 拍下一单并付款

**第二步：观察是否自动发货**

1. 用拍单的账号查看「我的订单」
2. 查看是否有自动发送的消息
3. 检查收到的链接和提取码是否正确

**第三步：尝试下载**

1. 复制收到的百度网盘链接
2. 打开链接，输入提取码
3. 确认能否正常下载/查看内容

### 6.3 测试成功标准

```
✅ 订单状态显示"已发货"
✅ 买家收到百度网盘链接
✅ 买家能正常打开链接
✅ 买家能正常下载内容
✅ 内容与描述一致
```

### 6.4 测试失败怎么办

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 没有自动发货 | 插件未开启/规则未激活 | 检查订单天使是否运行，检查规则开关 |
| 链接打不开 | 链接失效/密码错误 | 重新生成链接，确认密码正确 |
| 内容不对 | 发货内容设置错误 | 重新编辑发货内容 |
| 密码错误 | 复制粘贴出错 | 重新检查提取码 |

## 第七步：上架商品到淘宝

### 7.1 发布商品入口

1. 打开千牛工作台
2. 点击「商品管理」
3. 点击「发布宝贝」
4. 选择商品类目

### 7.2 填写商品信息

**商品标题**

标题公式：
```
产品名称 + 适用人群 + 关键词 + 促销词
```

示例：
```
简历模板合集 大学生求职 通用版 免费修改 Word文档 送面试技巧
```

**商品主图**

要求：
- 尺寸：800x800像素以上
- 清晰，不要有水印
- 突出产品价值
- 可以用Canva/稿定设计制作

**商品详情页**

必备要素：
1. 产品介绍（包含哪些内容）
2. 适用人群（谁需要买）
3. 使用方法（怎么用）
4. 常见问题（FAQ）
5. 售后说明（虚拟产品一经售出不可退款）

### 7.3 设置价格和库存

- 价格：根据产品价值定价，新手建议 ¥9-99
- 库存：设置为"无限"或较大数字（如：999）
- 运费：选择"包邮"或"0元运费"

### 7.4 发布商品

1. 检查所有信息填写完整
2. 点击「发布」
3. 商品审核（一般几小时）
4. 审核通过后，商品上线

## 进阶技巧

### 技巧一：多个产品共用一个百度网盘账号

如果有多个产品，可以：
1. 在百度网盘创建多个文件夹
2. 每个文件夹单独生成链接和密码
3. 在订单天使中创建多个发货内容
4. 每个产品关联对应的发货内容

### 技巧二：设置自动回复话术

在订单天使中设置自动回复：

```
亲，感谢购买！您的资料已发送，请查收。
如链接无法打开，请联系客服。
祝您使用愉快！🌟
```

### 技巧三：防止资源被转卖

1. 不要设置太简单的提取码
2. 定期更换链接和密码
3. 资料中加水印（但不要影响正常使用）
4. 百度网盘会员可以设置限速（让客户下载慢但能下）

### 技巧四：处理退款

虚拟产品退款处理：
1. 客户申请退款 → 进入千牛处理
2. 如果客户未收到货 → 直接同意退款
3. 如果客户已下载 → 酌情处理（一般可部分退款或拒绝）
4. 在商品详情页写明退款政策，减少纠纷

## 常见问题解答

### Q1：百度网盘需要开会员才能分享吗？

**不需要**。普通百度网盘账号也可以分享文件，生成链接。只是：
- 会员有更大空间（2TB vs 2TB普通版）
- 会员下载更快（普通账号限速严重）
- 会员可以设置长期有效的链接

**新手建议**：先用普通账号测试，确认能跑通再决定是否开会员。

### Q2：客户打开链接显示"文件不存在"？

原因：
1. 分享链接过期 → 设置为永久有效
2. 文件被删除 → 检查百度网盘文件是否还在
3. 文件夹分享改成文件分享 → 只分享单个文件

解决方法：
1. 重新生成分享链接，设置永久有效
2. 更新订单天使中的发货内容
3. 联系老客户重新发送新链接

### Q3：客户说提取码不对？

原因：
1. 你填错了提取码
2. 复制粘贴时出错
3. 大小写问题（中英文）

解决方法：
1. 仔细核对提取码
2. 在订单天使中重新编辑发货内容
3. 手动给客户重发正确的提取码

### Q4：自动发货插件收费吗？

大部分插件有**免费基础版**，功能足够新手使用。

| 插件 | 免费功能 | 付费功能 |
|------|----------|----------|
| 订单天使 | 自动发货、订单管理 | 批量处理、统计分析 |
| 智能自动发货 | 基础自动发货 | 高级自动化 |

**建议**：先用免费版跑通流程，有需要再升级付费版。

### Q5：闲鱼/小红书怎么自动发货？

**闲鱼**：暂不支持全自动发货，需要手动发送链接。
- 设置快捷回复语
- 客户付款后及时回复
- 手动复制粘贴链接和密码

**小红书**：也是手动为主。
- 客户私信 → 发购买链接 → 付款后私信发送链接
- 可以用自动回复助手辅助

### Q6：可以同时在多个平台卖吗？

可以。但需要注意：
1. 每个平台单独设置自动发货
2. 库存和发货内容可以共用
3. 价格可以不同（各平台定价策略不同）
4. 客户来自不同平台，互不影响
