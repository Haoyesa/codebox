## 十、常见问题与解决

### 问题1：AI写得太生硬

```
在Prompt最后加这段：
"请用口语化、有温度的方式写作，
读起来像朋友之间的聊天，不要像教科书。
可以适当用'其实'、'不过'、'但是'等转折词增加真实感。"
```

### 问题2：内容太泛泛

```
在Prompt中加入：
"请给出具体的操作步骤，不要只说原则。
每一个要点都要有'怎么做'，不是'为什么'。
最好能举例说明，举具体例子。"
```

### 问题3：结尾不会引导

```
在Prompt中加入：
"结尾请用这种方式引导：
'你们有没有类似的经历？评论区聊聊～'
'还有什么想知道的？告诉我！'
'觉得有用的话记得收藏哦～'"

不要用：
'求点赞'
'求关注'
'帮忙转发'
```

### 问题4：敏感词问题

```
在Prompt中加入：
"以下词汇禁止出现：
['日赚', '躺赚', '月入过万', '暴富', '最低价', '保证'...]
请用中性词替换，如：'增加收入'、'实用'、'划算'等。"
```
