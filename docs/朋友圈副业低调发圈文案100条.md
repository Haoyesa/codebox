## 使用说明

```
✅ 适合场景：
· 个人朋友圈（非营销号）
· 副业刚起步，不想刷屏被人拉黑
· 想自然展示，不显得刻意
· 低调含蓄，不炫耀收入

✅ 发布频率：
· 每天最多1-2条
· 早晚各一条最佳
· 不要连续发多条

✅ 组合使用：
· 2条日常 + 1条成果 + 1条引导 = 一组朋友圈

✅ 时间建议：
· 早7-9点（通勤/早餐）
· 中12-14点（午休）
· 晚20-22点（下班后）
```

## 发圈黄金组合模板

```
日常组合（不刷屏版）：
┌─────────────────────────────────┐
│ 早上：发一条状态记录（工作进展）   │
│ 下午：发一条经验分享（干货）       │
│ 晚上：发一条成果展示（低调）       │
│         或 咨询引导（自然）        │
└─────────────────────────────────┘

不刷屏原则：
· 一天不超过2条
· 连续两天不发，保持"正常人"状态
· 有成交才发成果，没成交就发日常
· 咨询引导型一个月发2-3条即可
```

## 注意事项

```
❌ 避免：
· 不要发"今天又赚了XXX"（太炫耀）
· 不要发"躺赚/日入过万"（虚假宣传）
· 不要连续刷屏发广告（被拉黑）
· 不要发"限量100份"等紧迫感（太营销）
· 不要发收款截图（显摆）

✅ 正确姿势：
· 展示过程，不展示结果
· 展示努力，不展示收入
· 展示价值，不展示价格
· 展示真实，不展示浮夸
```
