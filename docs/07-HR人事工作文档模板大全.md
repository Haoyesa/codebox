### 【入职流程说明】

```
【新员工入职流程】

一、发放录用通知
· 人事部向候选人发放《录用通知书》
· 候选人确认Offer

二、入职准备
· 准备工位和办公设备
· 开通企业邮箱和OA账号
· 准备工牌、门禁卡等

三、入职当天
1. 签署劳动合同（一式两份）
2. 填写员工入职登记表
3. 提交入职材料（身份证、学历证明、离职证明等）
4. 开通门禁权限
5. 发放工牌、工位
6. 介绍部门同事和直接上级
7. 新员工培训（公司介绍、制度讲解等）

四、试用期安排
· 试用期[3/6]个月
· 制定试用期工作目标
· 指定带教人
· 试用期考核（第[1/3/6]个月）

五、转正流程
· 员工提交转正申请
· 直接上级评估
· 人事部审核
· 办理转正手续
```

### 【离职流程说明】

```
【员工离职流程】

一、员工提出离职
· 员工提交书面《离职申请表》
· 部门负责人与员工沟通
· 确认离职意向

二、工作交接
· 部门安排工作交接
· 交接人、接收人签字确认
· 填写《工作交接清单》

三、物品归还
· 归还门禁卡、工牌、笔记本等
· 填写《物品归还清单》
· IT部门注销系统账号

四、薪资结算
· 计算应发工资
· 扣除社保公积金、个人所得税等
· 确认实发工资金额

五、离职证明
· 开具《离职证明》
· 办理档案转移手续（如有）

六、正式离职
· 完成所有手续
· 员工正式离职
```
